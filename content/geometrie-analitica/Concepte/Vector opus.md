Dacă $\vec{AB} = \vec{a}$, atunci **vectorul opus** lui $\vec{a}$ este $-\vec{a} = \vec{BA}$.

- Același modul, aceeași direcție, **sens opus**: $\vec{a} \uparrow\downarrow (-\vec{a})$, $\lvert-\vec a\rvert = \lvert\vec a\rvert$.
- $-(-\vec{a}) = \vec{a}$ și $-\vec{0} = \vec{0}$.
- $\vec{a} + (-\vec{a}) = \vec{0}$ — este elementul opus în [[Spațiu vectorial|structura de spațiu vectorial]].
- Coincide cu $(-1) \cdot \vec{a}$ — vezi [[Produsul vectorului la un număr]].
- Scăderea se reduce la el: $\vec{a} - \vec{b} = \vec{a} + (-\vec{b})$.
