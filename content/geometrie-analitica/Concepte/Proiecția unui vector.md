Pe axele unui sistem afin, cu $\vec{a} = \vec{OA} = \vec{OA_1} + \vec{OA_2}$:

| | Geometrică | Algebrică |
|---|---|---|
| Ce este | **vector** pe axă | **număr** |
| Pe $(Ox)$ | $P_{(Ox)}\vec{a} = \vec{OA_1}$ | $\operatorname{pr}_{(Ox)}\vec{a} = x = \dfrac{\vec{OA_1}}{\vec{e}_1}$ |
| Pe $(Oy)$ | $P_{(Oy)}\vec{a} = \vec{OA_2}$ | $\operatorname{pr}_{(Oy)}\vec{a} = y = \dfrac{\vec{OA_2}}{\vec{e}_2}$ |

- Proiecția pe o axă se face **paralel cu cealaltă axă** (nu perpendicular, în general).
- Proiecțiile algebrice pe axe **sunt** coordonatele vectorului.
- **T. 10.4:** proiecția sumei = suma proiecțiilor, pentru ambele tipuri de proiecție.
