## Preistoria disciplinei (filosofie)

| Perioadă | Reper |
|---|---|
| sec. IV î.Hr. | **Aristotel**, *Despre suflet* — primul tratat sistematic despre viața psihică |
| sec. XVII | **Descartes** — dualismul minte–corp; problema rămâne deschisă și azi |
| sec. XVII–XVIII | **Empiriștii britanici** (Locke, Hume) — asociaționismul; mintea ca *tabula rasa* |

## Constituirea ca știință

| An | Eveniment |
|---|---|
| ~1850–1860 | **Helmholtz** măsoară viteza influxului nervos; **Weber** și **Fechner** fondează psihofizica — dovada că fenomenele psihice pot fi **măsurate** |
| 1859 | **Darwin**, *Originea speciilor* — psihicul capătă o funcție adaptativă |
| **1879** | ⭐ **[[Wilhelm Wundt]]** înființează primul **laborator de psihologie experimentală**, la **Leipzig** — actul de naștere al psihologiei ca știință |
| 1890 | **[[William James]]**, *The Principles of Psychology* → [[Funcționalism]] |
| 1900 | **[[Sigmund Freud]]**, *Interpretarea viselor* → [[Psihanaliză]] |
| ~1900 | **Pavlov** descrie condiționarea clasică |
| **1906** | 🇷🇴 **Rădulescu-Motru** — primul laborator de psihologie experimentală în România (București) |
| 1912 | **[[Max Wertheimer]]** — fenomenul phi → [[Gestaltism]] |
| **1913** | **[[John B. Watson]]** — manifestul behaviorist → [[Behaviorism]] |
| 1917 | **[[Wolfgang Köhler]]** — insight-ul la cimpanzei |
| 1920 | **Watson & Rayner** — „Micul Albert" → [[Etica cercetării psihologice]] |
| **1921** | 🇷🇴 **Ștefănescu-Goangă** — Institutul de Psihologie Experimentală, Cluj |
| anii 1920–30 | **[[Lev Vîgotski]]** — teoria socioculturală (redescoperită în Occident după 1962) |
| 1938 | **[[B. F. Skinner]]** — condiționarea operantă |
| anii 1950 | **[[Carl Rogers]]**, **[[Abraham Maslow]]** — [[Umanism]], „a treia forță" |
| **1956** | ⭐ „**Revoluția cognitivă**" — Chomsky, Miller, Newell & Simon |
| 1959 | **Chomsky** recenzează critic *Verbal Behavior* al lui Skinner |
| **1967** | **[[Ulric Neisser]]**, *Cognitive Psychology* → [[Cognitivism]] |

## Perioada contemporană

| An | Eveniment |
|---|---|
| 1977 | **Engel** — modelul **biopsihosocial** |
| 1977 | 🇷🇴 Psihologia e desființată ca specializare universitară în România |
| 1979 | **Raportul Belmont** — bazele eticii cercetării pe subiecți umani |
| anii 1980–90 | Dezvoltarea **neuroștiințelor cognitive** (imagistică funcțională) |
| 1990 | 🇷🇴 Reînființarea specializării în România |
| ~1998 | **Seligman** — **psihologia pozitivă** |
| **2004** | 🇷🇴 **Legea 213/2004** — reglementarea profesiei de psiholog |
| anii 2010 | **Criza replicabilității**; mișcarea pentru **știință deschisă** |
