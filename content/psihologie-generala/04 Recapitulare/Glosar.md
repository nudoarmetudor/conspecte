> Termeni din [[C01 — Introducere în psihologie]]. Ordonați alfabetic.

| Termen | Definiție |
|---|---|
| **Adaptare** | Echilibrul dinamic dintre persoană și mediu; rezultatul funcționării [[Sistemul psihic uman\|SPU]]. |
| **Aptitudini** | Însușiri care condiționează performanța într-o activitate. → [[Însușiri psihice]] |
| **Behaviorism** | Orientare care studiază exclusiv comportamentul observabil (S → R). → [[Behaviorism]] |
| **Caracter** | Latura relațional-valorică a personalității: atitudini, valori, trăsături morale. |
| **Cognitivism** | Orientare care studiază procesarea informației. → [[Cognitivism]] |
| **Comportament** | Manifestarea externă, observabilă a activității psihice. |
| **Confidențialitate** | Obligația de a proteja datele participanților. → [[Etica cercetării psihologice]] |
| **Consimțământ informat** | Acordul dat în cunoștință de cauză, cu drept de retragere oricând. |
| **Corelație** | Grad de asociere între variabile; **nu** implică relație cauzală. → [[Metode corelaționale]] |
| **Etalonare** | Stabilirea normelor de comparație pentru un test, pe un eșantion reprezentativ. |
| **Experiment** | Metodă cu manipularea VI și măsurarea VD; singura care permite inferență cauzală. |
| **Fidelitate** | Constanța rezultatelor unui test la reaplicare. |
| **Funcționalism** | Orientare centrată pe funcția adaptativă a conștiinței. → [[Funcționalism]] |
| **Gestalt** | Structură perceptivă organizată; „întregul e mai mult decât suma părților". |
| **Insight** | Restructurare bruscă a câmpului problemei; soluție apărută dintr-odată. |
| **Introspecție** | Observarea propriei vieți psihice; metoda [[Structuralism\|structuralismului]]. |
| **Ipoteză** | Predicție testabilă și falsificabilă, formulată înaintea colectării datelor. |
| **Însușiri psihice** | Trăsături stabile, transsituaționale ale persoanei. → [[Însușiri psihice]] |
| **Operaționalizare** | Traducerea unui concept abstract în indicatori măsurabili. |
| **Percepție** | Reflectarea obiectului **ca întreg**, în prezența lui. |
| **Procese cognitive** | Procese care asigură cunoașterea. → [[Procese cognitive]] |
| **Procese reglatorii** | Procese care energizează și direcționează conduita. → [[Procese reglatorii]] |
| **Psihanaliză** | Orientare centrată pe inconștient și conflictul intrapsihic. → [[Psihanaliză]] |
| **Psihic** | Formă specifică de reflectare, reglare și adaptare la realitate. |
| **Randomizare** | Repartizarea aleatorie a participanților pe grupuri; asigură echivalența lor la start. |
| **Reflectare** | Construirea unui model intern, activ și subiectiv, al realității. |
| **Reglare** | Orientarea și controlul conduitei pe baza modelului intern. |
| **Replicabilitate** | Posibilitatea ca un studiu să fie repetat de alți cercetători, cu aceleași rezultate. |
| **Reprezentare** | Imaginea unui obiect **în absența** lui. |
| **Senzație** | Reflectarea unei **însușiri izolate** a obiectului, în prezența lui. |
| **Stări psihice** | Fond tonic difuz și durabil al vieții psihice. → [[Stări psihice]] |
| **Structuralism** | Orientare care descompune conștiința în elemente. → [[Structuralism]] |
| **Temperament** | Latura dinamico-energetică a personalității. |
| **Test psihologic** | Probă standardizată cu validitate, fidelitate și etalonare. → [[Testul psihologic]] |
| **Validitate** | Măsura în care un instrument măsoară exact ce își propune. |
| **Variabilă dependentă (VD)** | Variabila **măsurată**; efectul presupus. |
| **Variabilă independentă (VI)** | Variabila **manipulată**; cauza presupusă. |
| **ZPD** | Zona proximei dezvoltări: distanța dintre ce poate copilul singur și ce poate cu sprijin. |
