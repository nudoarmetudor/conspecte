## Fundamente

Cine a înființat primul laborator de psihologie experimentală? :: Wilhelm Wundt

Unde și când a apărut primul laborator de psihologie experimentală? :: Leipzig, 1879

Ce studiază psihologia? :: Psihicul, comportamentul și relația persoanei cu mediul

Care sunt cele 4 componente ale obiectului de studiu al psihologiei? :: Procese psihice, stări psihice, însușiri psihice, comportament

Care sunt cele 3 funcții ale psihicului? :: Reflectare, reglare, adaptare

Ce înseamnă etimologic „psihologie"? :: *psyché* (suflet) + *lógos* (știință)

## Școli

Reprezentanții structuralismului :: Wundt, Titchener

Reprezentantul funcționalismului :: William James

Fondatorul psihanalizei :: Sigmund Freud

Reprezentanții behaviorismului :: Watson, Skinner

Reprezentanții gestaltismului :: Wertheimer, Köhler

Reprezentanții umanismului :: Rogers, Maslow

Reprezentantul cognitivismului :: Ulric Neisser

Reprezentantul orientării socioculturale :: Lev Vîgotski

Care e teza cursului despre raportul dintre orientări? :: Sunt perspective complementare, nu concurente

Formula-teză a gestaltismului :: „Întregul este mai mult decât suma părților"

Ce experiment a lansat gestaltismul? :: Fenomenul phi (Wertheimer, 1912)

Ce a demonstrat Köhler cu cimpanzeii? :: Învățarea prin insight (restructurare bruscă), nu prin încercare-eroare

Modelul explicativ al behaviorismului :: S → R (stimul → răspuns)

Metafora fondatoare a cognitivismului :: Mintea ca sistem de procesare a informației

Conceptul central al lui Vîgotski :: Zona proximei dezvoltări (ZPD)

## Sistemul psihic uman

Cele 5 caracteristici ale SPU :: Unitar, dinamic, complex, ierarhizat, autoreglabil

Procesele cognitive senzoriale :: Senzații, percepții, reprezentări

Procesele cognitive superioare :: Gândire, limbaj, imaginație

Cele 4 procese reglatorii :: Motivație, afectivitate, voință, atenție

Cele 4 stări psihice din curs :: Activare, tensiune, relaxare, dispoziție

Cele 3 însușiri psihice :: Temperament, caracter, aptitudini

Ce deosebește senzația de percepție? :: Senzația reflectă o însușire izolată; percepția reflectă obiectul ca întreg

Ce deosebește percepția de reprezentare? :: Percepția are loc în prezența obiectului, reprezentarea în absența lui

Temperament, caracter, aptitudini — la ce întrebări răspund? :: Cum faci / de ce faci / cât de bine faci

## Metodologie

Cele 7 metode de cercetare din curs :: Observația, experimentul, ancheta, testul psihologic, studiul de caz, analiza produselor activității, metodele corelaționale

Singura metodă care permite concluzii cauzale :: Experimentul

Ce se manipulează într-un experiment? :: Variabila independentă (VI)

Ce se măsoară într-un experiment? :: Variabila dependentă (VD)

Cele 3 calități psihometrice ale unui test :: Validitate, fidelitate, etalonare

Ce e validitatea unui test? :: Măsoară ce își propune să măsoare

Ce e fidelitatea unui test? :: Dă rezultate constante la reaplicare

Ce e etalonarea? :: Stabilirea normelor de comparație pe un eșantion reprezentativ

E fidelitatea suficientă pentru validitate? :: Nu — e necesară, dar nu suficientă (un cântar dereglat e fidel și invalid)

Cele 2 forme ale anchetei :: Chestionarul și interviul

Baza comună a tuturor metodelor :: Etică, consimțământ informat, confidențialitate, rigoare, replicabilitate

După ce se alege metoda de cercetare? :: După întrebare, ipoteză, participanți și context

De ce corelația nu demonstrează cauzalitate? :: Pentru că relația poate fi inversă, poate exista o a treia variabilă, sau poate fi o coincidență

Între ce valori variază coeficientul de corelație? :: Între −1 și +1

## Sarcini

Cele 4 sarcini clasice ale psihologiei :: Descriere, explicație, predicție, prevenție și intervenție

Întrebarea sarcinii de descriere :: Ce se întâmplă?

Întrebarea sarcinii de explicație :: De ce se întâmplă?

Întrebarea sarcinii de predicție :: În ce condiții poate apărea?

Cele 5 ramuri fundamentale :: Psihologia generală, a dezvoltării, socială, cognitivă, psihofiziologia
