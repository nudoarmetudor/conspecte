**Reperul polar** $R = \{O,\ \vec i\}$, pe planul orientat, determină:

- **polul** $O$;
- **axa polară** $[OE)$, cu sensul pozitiv dat de $\vec i = \vec{OE}$, $\lvert\vec i\rvert = 1$.

Pentru un punct $M$: **raza polară** $r = \rho(O, M)$ și **unghiul polar** $\varphi = \widehat{(\vec i,\ \vec{OM})}$. Se notează $M(r;\ \varphi)$.

$$
0 \le r < \infty, \qquad 0 \le \varphi < 2\pi
$$

(pentru comoditate se admit și unghiuri negative: $M(3; -\tfrac{\pi}{2}) = M(3; \tfrac{3\pi}{2})$).

| | |
|---|---|
| polare → carteziene | $x = r\cos\varphi$, $y = r\sin\varphi$ |
| carteziene → polare | $r = \sqrt{x^2+y^2}$; $\cos\varphi = x/r$, $\sin\varphi = y/r$ |

> **Polul este excepția.** Corespondența punct ↔ pereche este biunivocă doar pe $P \setminus \{O\}$: pentru $M = O$ avem $r = 0$, iar $\varphi$ este **nedeterminat** (vectorul nul nu are direcție).
>
> **Nu folosiți $\operatorname{tg}\varphi = y/x$ singură** — nu distinge cadranele opuse. Perechea $(\cos\varphi, \sin\varphi)$ o face.

Un singur vector de bază, nu doi: rolul celui de-al doilea îl joacă [[Orientarea planului|orientarea planului]], care fixează sensul de măsurare a unghiului.
