Logică de ordin zero (logica predicatelor este de ordinul întâi)

Folosim
- Mulțime de bază
- Operații
- Variabile
- Formule
- Funcții

Mulțimi numărabile
Conectori logici - negația și implicația
Simboluri
Expr - mulțimea expresiilor
Expresia vidă - lambda
Formule

Dacă phi este o formulă atunci când exact una din următoarele alternative are loc:
- phi = v, unde v aparține V
- phi = nu(psi), unde psi este formulă
- phi = (psi implică omega), unde psi și omega sunt formule

Negația.
Prin negația propoziției p înțelegem o propoziție non-p care este falsă atunci când p este adevărată și adevărată când p nu este adevărată.

Disjuncția
Fiind date p și q, creăm o nouă propoziție care leagă aceste 2 propoziții. Disjuncția p și q este o propoziție compusă p sau q care este falsă atunci și numai atunci când fiecare dintre propozițiile p și q sunt false.

Conjuncția
Fiind date p și q, creăm o nouă propoziție care leagă aceste 2 propoziții. Conjuncția p și q este o propoziție compusă p și q care este adevărată atunci și numai atunci când fiecare dintre propozițiile p și q sunt adevărate.
